Hobby Project

Dragon Warrior

An early Snake-style puzzle game, originally built in 2016 as a university web development assignment (ELTE IK, Web Development 2) with vanilla HTML, CSS and JavaScript. Pick a grid size, then use the arrow keys to move.

Dragon Warrior

  Gluttony: +10 Growth
  Heart: +1 Life (5 max)

Use the arrow keys to move. Best played on a desktop with a keyboard.
