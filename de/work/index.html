  • Reworked ticket modelling around Shopify product variants, line items, and capacity constraints
  • Stabilized supporting Shopify app infrastructure for capacity, check-in, season tickets, and operational workflows

Edenmoor, formerly Pipers Farm

Checkout UI Extension for Delivery Date Selection

Checkout customization for Edenmoor, formerly Pipers Farm, moving delivery date selection into Shopify checkout so available dates and shipping methods could respond to postcode and cart-specific delivery constraints. I built the Checkout UI Extension with React, Remix, Node.js, and Shopify UI Extensions, including validation that could block checkout until a valid delivery date was selected.

  • Built a Shopify Checkout UI Extension for delivery date selection
  • Moved delivery date selection into checkout where postcode and shipping context are available
  • Added checkout validation to require a valid delivery date
  • Implemented extension-side shipping method logic based on selected date and delivery constraints
  • Supported additional storefront UI and design implementation work during the engagement
