Többnyelvű Shopify storefront fejlesztés

Shopify storefront fejlesztés FaceTheory számára ügynökségi csapaton keresztül, komplex többnyelvű setupban, ahol a lokalizált storefrontok külön repókban voltak karbantartva. A munka arra fókuszált, hogy a frontend implementáció, production javítások, UI finomítások és Core Web Vitals javítások egy nehéz storefront környezetben is következetesek maradjanak.
