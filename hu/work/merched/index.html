Merched

Egyedi nyomatválasztás és Shopify termékszinkron

Shopify storefront és adatmunka a Merched számára, beleértve egy egyedi nyomatválasztási élményt a termékoldalon, amely a kiválasztott nyomatot a kosárba is átviszi, plusz egy heti Stella Stanley API szinkront, amely a Shopify termékeket, variánsokat, készletet, árakat és metafieldeket egy ütemezett GitHub Actions workflow-n keresztül naprakészen tartja.
